Рабочая папка (Working Directory) — это текущая папка на компьютере со всеми файлами проекта, с которыми ведется непосредственная работа (создание, редактирование, удаление). Изменения в этой папке Git пока просто замечает, но еще не сохранил в историю.

Индекс (Index / Staging Area) — это промежуточная «подготовительная зона». Сюда с помощью команды `git add` добавляются файлы, изменения в которых отобраны и готовы войти в следующий коммит.

Коммит (Commit) — это зафиксированный снимок (снапшот) состояния файлов из индекса на определенный момент времени. Он сохраняется в историю Git с сообщением о том, какие именно изменения были внесены.




Git — это локальная система контроля версий, работающая на компьютере и отслеживающая историю изменений файлов.
GitHub — это облачный сервис для хранения Git-репозиториев в сети и совместной работы.



 `git diff` — сравнивает изменения в рабочей папке с индексом (показывает незакоммиченные и еще не добавленные через `git add` изменения).
 `git diff --staged` — сравнивает изменения в индексе с последним коммитом (показывает то, что уже подготовлено к коммиту).
